Imprivata Mobile Access Management REST API
 1.0 

[ Base URL: /api/v1 ]
/api-docs.yml

This page provides documentation for the Mobile Access Management REST API v1. This page also allows live queries, which can be very helpful when learning this system. To get started, use the Imprivata MAM admin console and visit Admin > API. Create an API key, and copy it to the clipboard. Then on this page click the “Authorize” button below, and paste the key.

Contact Imprivata MAM Support

Activities

GET/activities/find
Get all deployments since timestamp
GET/activities/findFromId
All deployments since specified Activity ID
GET/activities/getById
Get one deployment with details

Custom Attributes

GET/customfields/find/all
Get all Custom Attributes
GET/customfields/find/name/{name}
Search for Custom Attribute
GET/customfields/find/fieldtype/{fieldType}
Search for Custom Attributes by Type
POST/customfields/add
Add a new Custom Attribute

Devices

GET/devices/find/all
Get all devices
GET/devices/findBy/{field}/{value}
Get multiple devices
GET/devices/getBy/{field}/{value}
Get one device
GET/devices/activities/{field}/{value}
Get deployment IDs for a device
POST/devices/add
Add a new device
POST/devices/update/{field}/{value}
Update device by id, serial, uuid
POST/devices/bulkUpdate
Change custom attributes for several devices
POST/devices/deploy/serial/{serial}
Deploy a specific workflow to a device
POST/devices/evaluate/{field}/{value}
Evaluate policies to simulate unplug/replug
POST/devices/forcerecovery/serial/{value}
Force recovery mode on unpaired device
GET/evaluateForDevice/{udid}
Evaluate policies on the device matching the provided udid

POST/launchpads/checkout/{field}/{value}
Checkout a Device from Launchpad
